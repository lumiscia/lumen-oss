# Implementation Plan: Lumen Rendering Engine Rewrite

**Branch**: `001-lumen-rewrite` | **Date**: 2026-02-22 | **Spec**: [spec.md](spec.md)

## Summary

Complete the Lumen compositing and rendering engine — a Skia-based, Taffy-layout, multi-backend renderer written in Rust 2024 — by replacing all debug-placeholder output with real rendering across every clip type. The architectural foundation is solid: trait abstractions, backend dispatch, style property generics, module layout, `ClipType` enum dispatch, frame-aware keyframe interpolation with easing, expression AST + evaluator, dependency topological sort (Kahn), clip geometry and anchoring, shape fill/stroke with gradients, border/clip radius, image pixel rendering with fit modes, and `VideoClip` timeline mapping are all complete. Remaining work is organized into three priority bands: P1 (text shaping, layout content rendering, shadow blur), P2 (FFmpeg decode pipeline, worker thread prefetch, scene/layer model, masks), and Polish (tracing, builder helpers, snapshot tests, fuzz tests).

## Constitution Check

No formal constitution has been ratified. The following conventions are observed across the existing codebase and must be enforced in all new code:

| Convention | Rule |
|------------|------|
| **Enum dispatch** | `ClipType` and `ShapeKind` use exhaustive `match` — never `Box<dyn Clip>` or `dyn Trait` in the render path |
| **`thiserror` errors** | Every module defines a typed error enum with `#[derive(Debug, Error)]` |
| **Feature gating** | GPU backends behind `#[cfg(feature = "gpu-metal")]` / `#[cfg(feature = "gpu-vulkan")]`; `ffmpeg` behind `#[cfg(feature = "ffmpeg")]` |
| **Lazy GPU init** | `Option<GpuState>` initialized on first `render_frame`, not at construction |
| **Visibility discipline** | Internal types use `pub(super)` / `pub(crate)` / `pub(in crate::render)`; no accidental `pub` leakage |
| **Method over free function** | Any function whose first argument is `&Self` or `&mut Self` MUST be a method |
| **Multi-component style** | `[StyleProperty<T>; N]` not `StyleProperty<[T; N]>` — each component independently animatable |

## Detailed Implementation Notes

### P1-A: Shadow Rendering (proper Gaussian blur)

**File**: `crates/lumen/src/clip/style/base.rs`

`ShadowStyle` currently has `offset_x`, `offset_y`, `blur`, `color` and approximates blur via opacity division. This must be replaced:

1. **Change `BaseStyle::shadow: Option<ShadowStyle>` → `shadows: Vec<ShadowStyle>`**. All existing call sites pass a single shadow via `vec![shadow]`; empty vec means no shadows.

2. **Add fields to `ShadowStyle`**: `spread: StyleProperty<f32>` (signed — positive expands, negative contracts the shadow shape before blur); `inset: bool`.

3. **Outer shadow rendering** (in the shadow pass of `BaseStyle::draw`, before the main draw callback):
   - For each shadow in `shadows` where `inset == false`:
     - Save canvas state
     - Create a `Paint` with the shadow color
     - Set `paint.set_mask_filter(MaskFilter::blur(BlurStyle::Normal, blur / 2.0, false))`
     - Translate canvas by `(offset_x, offset_y)`
     - Expand the clip's bounding rect by `spread` on all sides
     - Draw the shadow shape (same geometry as the clip — rect, rrect, ellipse, or path) with this paint
     - Restore canvas state

4. **Inset shadow rendering** (after the main draw callback, so the clip content is already on canvas):
   - For each shadow where `inset == true`:
     - Save canvas state
     - Clip canvas to the element's shape (intersect)
     - Create a large rect that covers the whole frame, subtract the element's shape (contracted by `spread`) to get the "outside" shape
     - Translate by `(offset_x, offset_y)`, draw with Gaussian blur paint
     - Restore canvas state

5. **All shadow color channels** remain `[StyleProperty<u8>; 4]` — each independently animatable.

### P1-B: Text Rendering via `textlayout::Paragraph`

**Files**: `crates/lumen/src/clip/text.rs`, `crates/lumen/src/render/context.rs`

The current `TextClip::draw` draws a white box. Full replacement:

1. **`RendererContext` gets a `FontCollection` cache field**: `font_collection: Arc<Mutex<FontCollection>>` (or simply constructed once and stored). `FontCollection::new()` + `set_default_font_manager(FontMgr::default(), None)` — called once at construction, reused across all frames and all text clips.

2. **`TextClip::draw` implementation**:
   ```
   a. Resolve all TextStyle fields via StyleContext (font_size, font_weight, color channels, line_height, letter_spacing)
   b. Build ParagraphStyle:
      - set_text_align(resolved text_align)
      - set_max_lines(max_lines) if Some
      - set_ellipsis("…") if overflow == Ellipsis
   c. Build SkTextStyle (skia_safe::textlayout::TextStyle):
      - set_font_size(resolved font_size)
      - set_color(resolved RGBA color)
      - set_font_families(&[font_family])
      - set_height(resolved line_height)
      - set_letter_spacing(resolved letter_spacing)
      - set_font_style(FontStyle::new(weight, width, slant))
      - set_decoration (if Underline or Strikethrough)
   d. Build paragraph:
      - ParagraphBuilder::new(&para_style, &font_collection)
      - builder.push_style(&text_style)
      - builder.add_text(&self.content)
      - let mut paragraph = builder.build()
   e. Layout: paragraph.layout(max_width.unwrap_or(f32::MAX))
   f. Handle vertical_align: offset_y = match vertical_align { Top => 0, Middle => (h - paragraph.height()) / 2, Bottom => h - paragraph.height() }
   g. paragraph.paint(canvas, (0.0, offset_y))
   ```

3. **`TextClip::measure(available_width: f32, ctx: &StyleContext) -> (f32, f32)`**:
   - Same build steps as above (resolve font fields, build paragraph)
   - `paragraph.layout(available_width)`
   - Return `(paragraph.longest_line(), paragraph.height())`
   - This function is called by the Taffy `MeasureFunc` registered for text layout nodes

4. **Font family fallback**: If the requested font family produces zero glyphs, `FontMgr::default()` is already set as fallback — Skia handles this automatically.

### P1-C: Layout Text Measure Function

**File**: `crates/lumen/src/clip/layout.rs`

When building the Taffy tree from `LayoutNode`:
- For every `LayoutNode` whose `content` is `Some(LayoutContent::Text(text_clip))`:
  - After inserting the Taffy node, register a `MeasureFunc`:
    ```rust
    tree.set_measure_func(node_id, MeasureFunc::Boxed(Box::new(
        move |known_dimensions, available_space, _node_id, _node_context| {
            let width = known_dimensions.width
                .unwrap_or(available_space.width.unwrap_or(f32::MAX));
            let (w, h) = text_clip.measure(width, &ctx);
            taffy::geometry::Size { width: w, height: h }
        }
    )));
    ```
  - This is what allows Taffy to size text nodes using intrinsic text metrics rather than fixed dimensions.

**Overflow clipping**: In the layout render traversal, after translating the canvas to the node's computed position:
- If the node's `style.overflow` is `Hidden`, call `canvas.clip_rect(Rect::from_wh(w, h), ClipOp::Intersect, true)` before drawing content and recursing into children.

### P2-A: Masks

**File**: `crates/lumen/src/clip/style/base.rs`

New types:

```rust
pub enum MaskSource {
    Shape(MaskShape),
    Bitmap { source: String },
    Clip { clip_id: String },
}

pub enum MaskShape {
    Rectangle { x: StyleProperty<f32>, y: StyleProperty<f32>,
                width: StyleProperty<f32>, height: StyleProperty<f32>,
                corner_radius: [StyleProperty<f32>; 4] },
    Ellipse { cx: StyleProperty<f32>, cy: StyleProperty<f32>,
              rx: StyleProperty<f32>, ry: StyleProperty<f32> },
    Path { data: Vec<PathCommand> },
}

pub struct Mask {
    pub source: MaskSource,
    pub inverted: bool,
}
```

Add `mask: Option<Mask>` to `BaseStyle`.

Rendering in `BaseStyle::draw`, after setting up transform but before calling the draw callback:

- **`MaskSource::Shape`**: Build a Skia `Path` from the resolved `MaskShape` geometry. Call `canvas.clip_path(&path, if inverted { ClipOp::Difference } else { ClipOp::Intersect }, true)`. The canvas save/restore in `BaseStyle::draw` automatically restores the clip state.

- **`MaskSource::Bitmap`**: Create a temporary Skia surface matching the clip bounds. Render clip content into it (run draw callback on the temp surface). Create another temp surface, decode and draw the mask image into it. Composite: set paint blend mode to `BlendMode::DstIn` (or `DstOut` if inverted), draw the mask surface onto the content surface. Draw the result onto the main canvas.

- **`MaskSource::Clip`**: Same as Bitmap, but instead of decoding an image, render the referenced clip into the mask surface. The referenced clip's render must appear before the masked clip in the dependency order — the dependency builder must add a `ClipRender(mask_source_id) → ClipRender(masked_clip_id)` edge.

**Dependency builder change** (`dependency/mod.rs`): When scanning a clip's `BaseStyle`, if `mask.source == MaskSource::Clip { clip_id }`, add an edge: `DependencyNode::ClipRender(clip_id) → DependencyNode::ClipRender(current_clip_id)`.

#### PTS Mapping

```rust
impl LibavStreamDecoder {
    fn source_frame_to_pts(&self, frame: u64) -> i64 {
        let secs = frame as f64 * self.timeline_time_base.0 as f64
                   / self.timeline_time_base.1 as f64;
        (secs * self.time_base.1 as f64 / self.time_base.0 as f64).round() as i64
    }

    fn pts_to_source_frame(&self, pts: i64) -> u64 {
        let secs = pts as f64 * self.time_base.0 as f64 / self.time_base.1 as f64;
        (secs * self.timeline_time_base.1 as f64 / self.timeline_time_base.0 as f64)
            .round().max(0.0) as u64
    }
}
```

#### Frame Retrieval (`get_frame`)

1. Check `cache.get(&target_frame)` — return clone if hit.
2. If `target_frame < self.next_source_frame`: seek backward.
   - Attempt `input_ctx.seek(target_pts, ..target_pts)`.
   - On failure: reopen source from start (`ffmpeg::format::input(&path)`) and reset all state.
3. Decode forward: loop `receive_packet → send_packet → receive_frame` until decoded frame's PTS ≥ target PTS.
   - For each decoded frame: convert with `scaler.run(&decoded_frame, &scratch_frame)`, copy RGBA from `scratch_frame.data(0)` (handling stride), store `FrameImage` in LRU cache.
   - **Gap filling**: if `source_frame - last_decoded > 1`, fill gap indices by storing the last image for all intermediate frames.
4. If exact frame is in cache, return it. If not (seek landed past target), return nearest prior frame.

#### swscale RGBA Conversion

```rust
let scaler = scaling::Context::get(
    decoder.format(), width, height,
    ffmpeg::format::Pixel::RGBA,
    width, height,
    scaling::Flags::FAST_BILINEAR,
```

After `scaler.run(&decoded, &mut scratch)`:
```rust
let stride = scratch.stride(0);
let data = scratch.data(0);
let row_bytes = (width * 4) as usize;
let mut rgba = buffer_pool.pop().unwrap_or_else(|| vec![0u8; width as usize * height as usize * 4]);
for row in 0..height as usize {
    let src = &data[row * stride .. row * stride + row_bytes];
    let dst = &mut rgba[row * row_bytes .. (row + 1) * row_bytes];
    dst.copy_from_slice(src);
}
```

#### Hardware Decode

```rust
fn try_hw_decode(decoder_ctx: *mut AVCodecContext, device_type_name: &str) -> bool {
    let cname = CString::new(device_type_name).unwrap();
    unsafe {
        let device_type = ffi::av_hwdevice_find_type_by_name(cname.as_ptr());
        if device_type == ffi::AVHWDeviceType::AV_HWDEVICE_TYPE_NONE { return false; }
        let mut device_ctx: *mut ffi::AVBufferRef = ptr::null_mut();
        let ret = ffi::av_hwdevice_ctx_create(&mut device_ctx, device_type,
                                               ptr::null(), ptr::null_mut(), 0);
        if ret < 0 { return false; }
        (*decoder_ctx).hw_device_ctx = device_ctx;
        (*decoder_ctx).extra_hw_frames = 8;
        true
    }
}

fn hw_candidates() -> &'static [&'static str] {
    #[cfg(target_os = "macos")] return &["videotoolbox"];
    #[cfg(target_os = "linux")] return &["vaapi", "cuda", "qsv", "vulkan"];
    #[cfg(target_os = "windows")] return &["d3d11va", "dxva2", "qsv"];
    #[allow(unreachable_code)] &[]
}
```

When `LUMEN_LIBAV_HW_DEVICE=auto`, iterate `hw_candidates()` and try each. If all fail, proceed with software decode (log warning, do not error).

```rust
}

impl VideoDecodeWorker {
    pub fn spawn(source_id: &str, decoder: LibavStreamDecoder,
                 queue_cap: usize, prefetch_frames: u64) -> Self {
        let (tx, rx) = mpsc::sync_channel(queue_cap);
        let id = source_id.to_string();
        let handle = thread::spawn(move || run_decode_worker(id, decoder, rx, prefetch_frames));
        Self { source_id: source_id.to_string(), tx: Some(tx), handle: Some(handle) }
    }

    pub fn get_frame(&self, source_frame: u64) -> Result<Option<FrameImage>, FfmpegError> {
        let (reply_tx, reply_rx) = mpsc::sync_channel(1);
        self.tx.as_ref().unwrap().send(DecodeRequest { source_frame, reply: reply_tx })?;
        reply_rx.recv()?
    }
}

impl Drop for VideoDecodeWorker {
    fn drop(&mut self) {
        self.tx.take(); // close channel → worker loop exits on next recv()
        if let Some(h) = self.handle.take() { let _ = h.join(); }
    }
}
```

Worker loop with prefetch:

```rust
fn run_decode_worker(source_id: String, mut decoder: LibavStreamDecoder,
                     rx: mpsc::Receiver<DecodeRequest>, prefetch_frames: u64) {
    let mut last_requested: Option<u64> = None;

    while let Ok(req) = rx.recv() {
        let frame = req.source_frame;
        let result = decoder.get_frame(frame);

        // Detect access direction
        let direction = match last_requested {
            Some(last) if frame == last + 1 => Direction::Forward,
            Some(last) if frame + 1 == last => Direction::Reverse,
            _ => Direction::Random,
        };

        let _ = req.reply.send(result);

        // Prefetch after responding (non-blocking — just warms LRU)
        if prefetch_frames > 0 && direction != Direction::Random {
            for step in 1..=prefetch_frames {
                let next = match direction {
                    Direction::Forward => frame.checked_add(step),
                    Direction::Reverse => frame.checked_sub(step),
                    Direction::Random => unreachable!(),
                };
                match next.map(|f| decoder.get_frame(f)) {
                    Some(Ok(Some(_))) => {}
                    _ => break,
                }
            }
        }

        last_requested = Some(frame);
    }
}
```

**Configuration** (read at `VideoDecodeWorker::spawn` time, not per-frame):

| Env var | Default | Meaning |
|---------|---------|---------|
| `LUMEN_STREAM_CACHE_FRAMES` | 64 | LRU capacity per source |
| `LUMEN_LIBAV_PREFETCH_QUEUE` | 8 | `sync_channel` capacity |
| `LUMEN_LIBAV_PREFETCH_FRAMES` | 4 | frames to pre-decode after each request |

**Thread safety**:
- `LibavStreamDecoder` is `!Send` (FFmpeg C pointers). Apply `unsafe impl Send for LibavStreamDecoder` with doc comment: *"Safe because the decoder is moved to the worker thread at spawn time and never accessed from any other thread. The `VideoDecodeWorker` API ensures the channel is the only access path."*
- `FrameImage` = `Arc<Vec<u8>>` — `Send + Clone`, cheap clone across the channel.
- Skia surfaces on `RendererContext` stay on the render thread — never cross thread boundaries.

```
1. Validate: frame < scene.duration_frames → else RenderError::OutOfRange
2. Collect all expressions from all clips in all layers
3. DependencyPlan::build(&expressions) → topological sort → evaluation_order
4. Initialize ResultMap: HashMap::new()
5. For each DependencyNode in evaluation_order:
   a. ClipRender { clip_id, layer } → build ExpressionScope from ResultMap → draw clip → store computed x/y/w/h/opacity in ResultMap

6. For each Layer (bottom-to-top):
   a. If !layer.visible → skip
   b. Create layer surface (same dimensions as scene)
   c. For each clip in layer.clips where clip.contains_frame(frame): draw clip to layer surface
   d. Composite layer surface onto main canvas with layer.blend_mode and resolved layer.opacity
7. read_surface_rgba → Vec<u8>
```

### P2-F: Encoder Thread (MP4 Output)

**File**: `crates/lumen/src/ffmpeg/worker.rs` (feature = "ffmpeg")

```rust
pub fn render_to_mp4<F>(scene: &Scene, assets: &mut StreamingAssets,
                         renderer: &mut impl RenderBackend,
                         output_path: &Path,
                         on_progress: F) -> Result<(), FfmpegError>
where F: Fn(u32, u32)
{
    let queue_cap: usize = std::env::var("LUMEN_ENCODE_QUEUE")
        .ok().and_then(|v| v.parse().ok()).unwrap_or(8);

    let (tx, rx) = mpsc::sync_channel::<Vec<u8>>(queue_cap);
    let (w, h, fps) = (scene.width, scene.height, scene.frame_rate);
    let encode_handle = thread::spawn(move || encode_rgba_stream(w, h, fps, output_path, rx));

    for frame in 0..scene.duration_frames {
        let rgba = renderer.render_frame(scene, frame, assets)?;
        tx.send(rgba).map_err(|_| FfmpegError::EncodeChannelClosed)?;
        on_progress(frame + 1, scene.duration_frames);
    }

    drop(tx);
    encode_handle.join().map_err(|_| FfmpegError::EncodeThreadPanic)??;
    Ok(())
}
```

The `encode_rgba_stream` function reads from `rx`, encodes each frame as H.264 via libav, and muxes to the output container. The bounded `sync_channel` provides natural backpressure.

## Complexity Tracking

| Decision | Justification | Simpler Alternative Rejected Because |
|----------|---------------|--------------------------------------|
| `unsafe impl Send for LibavStreamDecoder` | FFmpeg C types include raw pointers which are `!Send` by default | Making the decoder `Arc<Mutex<...>>` would serialize all access; defeating the purpose of per-source worker threads |
| Per-source worker threads | Must decouple decode latency from render throughput to hit 24 fps target with 3× 1080p sources | Single-threaded decode would block the render thread during seek operations (~100–200 ms each) |
| Bounded LRU + buffer pool | Prevents OOM on long-form video; 64 × 1080p RGBA ≈ 512 MB per source | Unbounded cache would OOM; no cache would cause excessive seeks |
| `Arc<Vec<u8>>` for `FrameImage` | Makes cross-thread sharing cheap (reference-count bump) without copying frame data | `Vec<u8>` clone would copy 8 MB per frame; `&[u8]` lifetime would require complex lifetime bounds |
| Temporary surfaces for bitmap/clip masks | Required for correct alpha-compositing semantics (`DstIn` blend) | Canvas `clip_path` only supports geometric clipping, not alpha-channel-based masking |
| `OnceLock` for FFmpeg init | FFmpeg global init is not thread-safe if called concurrently | `std::sync::Once` is equivalent but `OnceLock` provides the init result without a separate `Result` variable |
