The browser preview loads every kind of media one way. What the engine lists the composition reading, joined with the page's `media` and `fonts`, decides what is fetched: images, videos, audio, models, environment maps and fonts each go `pending`, then `ready` or `failed`, and are released when the composition stops naming them.

- `session.whenReady()` and `preview.whenReady()` resolve once the current composition is shown and nothing it needs is pending, with the error that stopped it, an `audio_failed` error, or `null`. They never reject, and a composition, `media` or `fonts` change starts them again.
- `state.media` counts the composition's sources as `{ pending, ready, failed }` (the new `LumenPreviewMediaState` type).
- While anything is pending the preview holds its last frame, and playback holds too: the playhead stops and the audio pauses until everything has settled, so sound can't run ahead of the picture.
- Environment maps (`render_3d.environment_map`, Radiance `.hdr` or OpenEXR `.exr`) load from `media` like models. `LumenPreviewMediaKind` gains `"environment"`.
- Source names follow `lumen-server`'s rules, checked against a fixture both test suites read. The `@lumiscia/lumen-preview` README has the table.
- `runtimeUrl` on `mountPreview`, `LumenPreviewSession`, and the React and Svelte `Player` names one directory serving `worker.js`, `lumen_wasm_bg.wasm`, `audio-worker.js` and `audio-worklet.js`, and every runtime URL not passed on its own comes from it. With it, `wasmUrl` and `workerUrl` are optional. Without it nothing changes.
- The wasm controller gains `setEnvironment`, `hasEnvironment` and `removeEnvironmentSource`, and `LumenMediaTarget` gains them as optional members.

Breaking changes, each where the old behaviour differed between kinds:

| Before                                                                                                                                | After                                                                                                                                                      | Migrating                                                                                                      |
| ------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------- |
| Every `media` entry was fetched, and one whose kind couldn't be told failed the load with "needs a kind".                             | Only the entries the composition reads load. The rest are ignored, unless an expression computes a source.                                                 | None needed. An entry only an expression reads still needs `kind` when its blob's type doesn't say.            |
| A `kind` on an entry chose how it was read.                                                                                           | A `kind` the composition doesn't read the source as fails as `media.wrong_kind`.                                                                           | Drop the `kind`, or fix it to the kind the node reads.                                                         |
| A source written as a URL (`https://…`), with another `scheme://`, empty or with a `..` part loaded if `media` had an entry under it. | It fails as `media.not_found`, as it does on `lumen-server`.                                                                                               | Name the source (`intro.mp4`) and pass the URL in `media` under that name.                                     |
| Images, videos, models and fonts held the last frame while a composition loaded, but playback ran on and audio loaded on its own.     | Every kind holds the frame, and playback pauses while any source, audio included, is pending.                                                              | None needed. Await `whenReady()` before `play()` to start without the pause.                                   |
| Every `media` and `fonts` entry stayed registered while the page passed it, named by the composition or not.                          | Only what the composition names stays registered; the rest is unregistered and its memory freed. A source the old and new compositions share stays loaded. | None needed.                                                                                                   |
| `LumenPreviewTransport` had `pause`, `play` and `seek`.                                                                               | It also has `whenReady(): Promise<LumenPreviewError \| null>`.                                                                                             | A custom transport passed to `preview.attach()` implements `whenReady`.                                        |
| `/advanced` exported `MediaRegistration`, `RegisteredImageSource`, `RegisteredModelSource` and `RegisteredVideoSource`.               | Removed: the worker's `load` message carries `[source, entry]` pairs of the page's `media` instead, and the worker works out what to load.                 | A custom host passes the page's `media` entries; `@lumiscia/lumen-react` and `@lumiscia/lumen-svelte` do this. |
| `wasmUrl` and `workerUrl` were required on `LumenPreviewSessionOptions`.                                                              | Both are optional when `runtimeUrl` is set; without either, the session fails to start with `worker_failed`.                                               | None needed.                                                                                                   |
